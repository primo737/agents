# Offer composition guide

Use this when a client has several meaningful parts to one offer. A single, plain-language scope may serve better when the service is simple. The aim is to make delivery and benefits understandable, not to create an inflated “total value.”

## Gather the real terms

1. Approved offer name, target customer, price or pricing method, eligibility, start date, duration, capacity, and fulfilment owner.
2. Core deliverables and support: what the customer receives, when, through which channel, and at what service level.
3. Exclusions, dependencies, cancellation or renewal terms, and what happens if a client cannot use one component.
4. Proof for measurable outcomes and permission to use any testimonial, logo, or case study.
5. Any real bonus or guarantee, its delivery owner, terms, and approval status.

## Component worksheet

| Component | Function | Customer benefit | Delivery and timing | Evidence or limitation | Status |
|---|---|---|---|---|---|
| Core product/service | | | | | |
| Support or onboarding | | | | | |
| Optional add-on | | | | | |

Write benefits at three levels only when useful: the action made easier, the immediate practical effect, and the larger outcome the evidence can support. Do not turn a hoped-for transformation into a promise. If a component has an independently sold, current price, it may be cited with its source; otherwise do not assign a made-up dollar value.

## Output formats

**Customer-facing:** “The [approved offer] includes [real components]. It is for [audience] who need [supported outcome]. The price/next step is [approved term]. [Relevant exclusions or conditions].”

**Internal review:** List each component, approval owner, evidence, delivery capacity, and open term. Clearly mark proposals. A promotional deadline or limited capacity must reflect a real constraint, not invented urgency.

## Review

Can the team actually deliver every line? Do claims match the source? Are price and service boundaries approved? Are bonuses useful rather than filler? Does the explanation make the offer easier to evaluate? If the answer to the last question is no, use a simpler description.
