# Funnel pattern selection

These are planning patterns, not a required taxonomy or evidence that one path converts better. Start with the audience's decision process, the approved offer, delivery capacity, and the requested outcome. Choose the simplest path that lets the person make an informed next step. Add a page, form, call, sequence, or offer only when it serves that path.

| Goal | Possible path | Key decision |
|---|---|---|
| Explain a straightforward offer | Source → offer page → enquiry or checkout → confirmation | Is enough information available for a direct decision? |
| Qualify complex services | Source → service explanation → enquiry/application → human review → next step | Which questions are necessary before a useful conversation? |
| Share a useful resource | Source → resource page → access → optional relevant follow-up | Is contact capture necessary and permitted? |
| Demonstrate a product | Source → demo or trial → evaluation → purchase/contact | Can the prospect evaluate the product without unnecessary friction? |
| Invite event participation | Source → event details → registration → reminder → attendance/follow-up | Are capacity, timezone, recording, and permissions clear? |
| Sell online goods | Source → product details → cart/checkout → fulfilment/support | Are availability, delivery, returns, and payment clear? |
| Serve existing customers | Onboarding → use/support → feedback → renewal or referral | Does the next step benefit the customer and fit the approved service? |

Patterns can be combined, but do not assume a lead magnet, tripwire, webinar, upsell, application, retargeting audience, or multi-page sequence is necessary. Avoid using price bands alone to select a funnel. Test the path against actual audience behavior and delivery constraints. See [funnel structures](funnel-structures.md) for adaptable flow examples.
