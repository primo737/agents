# Story Extraction Bot - Quick Reference Card

# Story Extraction Bot - Quick Reference Card

## 🎯 THE GOAL
Extract stories from transcripts for **both** book writing and story mapping.
* * *

## 📋 MUST PRODUCE TWO OUTPUTS

### 📖 Output 1: BOOK CONTENT
**For**: Writing the book
**Format**: Full narrative prose
**Include**: Complete stories, teaching, and transitions
**Voice**: Speaker's authentic style preserved
**Length**: As long as needed (500-2000+ words per story)

### 🗺️ Output 2: SPEAKING ANALYSIS
**For**: Story mapping and talk preparation
**Format**: Strategic breakdown
**Include**: Categories, tags, triggers, and analysis
**Voice**: Analytical tone
**Length**: Concise summaries (200-400 words per story)
* * *

## ✅ BOOK CONTENT CHECKLIST

Must include:
- [ ] Full story as told (not summarized!)
- [ ] Speaker's exact phrasing and voice
- [ ] Conversational elements ("you know," "I mean")
- [ ] Teaching woven into the narrative
- [ ] Emotional beats and pauses
- [ ] Transitions before and after
- [ ] Setup context
- [ ] Complete narrative arc

Example:

```sql
"You know what's wild? I once met a billionaire who told me something that completely changed how I think about success..." [Full story continues with every detail]
```

* * *

## ✅ SPEAKING ANALYSIS CHECKLIST

Must include:
- [ ] Story title
- [ ] Duration estimate
- [ ] Primary category (Origin, Paradigm Shift, etc.)
- [ ] Memory triggers (NOT full story)
- [ ] Strategic WHY (why this story here?)
- [ ] 4MAT mapping (WHY/WHAT/HOWTO/WHATIF)
- [ ] Tags (topics, strategic, emotional, functional)
- [ ] Version options (short/medium/long)
- [ ] Alternative applications
- [ ] Related stories
* * *

## 🚫 COMMON MISTAKES

### DON'T:
❌ Summarize stories instead of preserving them
❌ Provide only one output
❌ Clean up voice too much
❌ Separate teaching from the story
❌ Use bullet points in book content
❌ Include full narrative in speaking analysis
❌ Ignore transitions
❌ Strip away emotional elements

### DO:
✅ Preserve full narratives
✅ Provide both outputs always
✅ Keep authentic voice
✅ Keep teaching embedded
✅ Use prose for book content
✅ Use triggers for speaking
✅ Include connective tissue
✅ Capture emotional journey
* * *

## 🏷️ KEY STORY CATEGORIES

**Strategic Types**:
*   Origin Story
*   Investment Story
*   Testimonial/Case Study
*   Moral Story
*   Instructional Story
*   Paradigm Shift Story
*   Allegorical/Metaphorical
*   Hero's Journey
*   Rock-Bottom Story
*   "Nothing Story"

**4MAT Components**:
*   WHY (Motivator)
*   WHAT (Teacher)
*   HOW TO (Coach)
*   WHAT IF (Mentor)

**Talk Positions**:
*   F-15 (Opening)
*   Core Point
*   L-15 (Closing)
* * *

## 📊 QUALITY CHECK

### Good Book Content Output:
✅ Multiple paragraphs per story
✅ Reads like the speaker talking
✅ Complete narrative with context
✅ Teaching naturally embedded
✅ Ready for book editing

### Good Speaking Analysis Output:
✅ Clear categorization
✅ Strategic insights included
✅ Searchable tags present
✅ Memory triggers (not full story)
✅ Mapping information complete
* * *

## 🔍 QUICK TROUBLESHOOTING

| Problem | Solution |
| ---| --- |
| Only getting summaries | Emphasize "full narrative for book" |
| Only one output | Request both explicitly |
| Voice too formal | Say "preserve conversational elements" |
| Stories fragmented | Say "keep complete narrative together" |
| No transitions | Say "include what came before/after" |

* * *

## 💡 THE KEY PRINCIPLE

**Book Content = What to PUT IN the book** (Actual paragraphs, full stories, speaker's voice)
**Speaking Analysis = How the STORY WORKS** (Meta-information, strategy, mapping tools)
Different purposes. Both essential. Never sacrifice one for the other.
* * *

## 📁 FILE ORGANIZATION

### For Book:

```plain
Book_Manuscript/
├── Chapter_01_Content.md
├── Chapter_02_Content.md
└── Story_Raw/
```

### For Speaking:

```plain
Story_Bank/
├── By_Category/
├── By_Duration/
└── Analysis/
```

* * *

## 🎯 SUCCESS = TWO OUTPUTS

Every transcript should generate:
1. **Book-ready content** you can copy/paste into the manuscript
2. **Strategic analysis** you can use for story mapping

If you're missing either one, the extraction isn't complete.
* * *

## 🚀 QUICK START

1. Feed transcript to bot
2. Say: "I need BOTH book content AND speaking analysis"
3. Verify you got full narratives
4. Verify you got strategic breakdowns
5. Organize into respective folders
6. Start writing/mapping!
* * *

## 📞 REMEMBER

**The bot serves two masters:**
*   The WRITER (needs content)
*   The SPEAKER (needs strategy)

Give each what they need. 🎯
